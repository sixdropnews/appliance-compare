# Appliance Compare

A fast, static website for browsing and comparing the full Azmy Co appliance catalogue: 718 products, 25 appliance types, 39 brands.

- Filter each appliance type by its own specs (doors and layout for fridges, panel type for TVs, load and capacity for washers, and so on)
- Compare up to 4 products side by side, and share the comparison as a link
- Best deals, brand pages, search, and product pages that link to azmyco.com to buy

Data collected from azmyco.com on 14 Nov 2026. Prices in EGP. Specs are read from each product's listed name.

Plain HTML, CSS and JavaScript; hosted on GitHub Pages.
