# Appliance Compare

A fast, static website that compares home appliance prices across six Egyptian stores: Azmy, B.TECH, Raya Shop, Carrefour, 2B and El Araby. It covers about 10,500 products, matched model by model across stores.

- See every store's price for the same model, which store is cheapest, and stock status
- Filter each appliance type by its own specs, plus by store, in-stock, and "sold by 2+ stores"
- Price-gap deals, store pages (cheapest here / cheaper elsewhere), brand pages and search by model code
- Compare up to 4 products side by side, with each store's price, and share the comparison as a link

Only home appliances are included. Data collected from the stores' public websites on 14 Nov 2026. Prices in EGP. Specs are read from each product's listed name. Not affiliated with any store.

Plain HTML, CSS and JavaScript; hosted on GitHub Pages. The data build script is in `../scripts/catalog.py`.
